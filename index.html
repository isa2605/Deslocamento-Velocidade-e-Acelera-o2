# Fórmulas Utilizadas


// 1. Deslocamento em linha reta

Δs = distância


// 2. Velocidade Média

v = Δs / t


// 3. Aceleração (Partindo do repouso: v0 = 0)

a = (2 * Δs) / t²


// 4. Segunda Lei de Newton (Dinâmica)

F = m * a
